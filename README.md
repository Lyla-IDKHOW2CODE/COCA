帮助本人快速高亮、查询COCA词频，兼学习ai vibe coding的产物
目前的功能：
    高亮：
      １.自动高亮COCA Rank 10000到35000的单词
          10000-15000（淡红色）
          15000-20000（淡紫色）
          30000-30000（淡绿色）
      ２.高亮加入生词本的单词
          （淡黄色）
      ３.取消高亮加入隐藏的单词
　　查词频：
      １.光标移至高亮单词自动显示具体COCA Rank
      ２.双击任意单词显示词频和快捷管理，加入生词本或隐藏
    高亮模式：
      １.全部高亮
      ２.仅生词本高亮
      ３.取消高亮
      ４.日间模式：背景色高亮；夜间模式：字体高亮并加下划线
    生词本＆隐藏
      １.生词本单词淡黄色高亮，隐藏单词不高亮
      ２.可手动输入，一键删除，以json格式导出
